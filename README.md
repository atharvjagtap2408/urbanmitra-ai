# UrbanMitra AI

A simple website that helps people write civic complaints and see local problem reports.

## What it does
- Lets the user choose an issue: pothole, streetlight, traffic signal, blocked drain, garbage, water leakage, or other
- Writes a complaint in English, Hindi, or Marathi
- Copy button for the complaint
- Reports feed with comments

## Current status
This is the first version, built with HTML, CSS and JavaScript.
- Complaints are made from fixed templates. AI is not added yet.
- The feed is saved only in the user's own browser. It is not shared between users.
- It does not send complaints to any office. The user copies the complaint and submits it on the official PMC CARE platform.
